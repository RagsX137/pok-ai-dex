Agentic Pokédex
Agentic Edition — Dark Dashboard

A full-stack Pokédex powered by Coveo Atomic for enterprise-grade search and a local Ollama LLM for on-device generative answers — all wrapped in a slick dark 3-column dashboard. Search any Pokémon by name, type, ability, or natural language; get AI-generated insights from Professor Oak; explore habitats on regional maps; and compare similar Pokémon side-by-side. No build step. No external LLM calls in the hot path. Just Flask + Coveo + local inference.

Flask 2.x Coveo Atomic v3 Ollama PokéAPI Python 3.11+ Vanilla JS (ESM)
Architecture
🔍
Coveo Atomic
Web component search engine. Headless engine proxied through Flask — API keys never reach the browser.
🤖
Ollama (local LLM)
llama3, mistral, gemma3, phi4 — any pulled model. Generates grounded RGA answers from Coveo search context.
🎓
Coveo CRGA
Coveo's Relevance Generative Answering (Professor Oak). SSE stream consumed server-side, returned as JSON.
🗄️
Flask API
Thin Python backend. Proxies Coveo REST, streams CRGA, serves the Ollama agent loop, and injects credentials.
🗺️
PokéAPI + Serebii
Stats, moves, types, and encounter locations fetched from PokéAPI. Region maps sourced from Serebii Pokéarth.
🖼️
PokémonDB Artwork
High-res Pokémon artwork from pokemondb.net CDN. Sprite fallback in the sidebar lens and similar-Pokémon grid.
Features
3-Column Dark Dashboard
Left sidebar (type chips + generation filter + map card), scrollable center column (search, photo, results, similar Pokémon), and a sticky right panel (stats, moves, type effectiveness, AI rec).
Natural Language Search
Ask anything — "fastest fire type", "best water starter", "which Pokémon evolves from Eevee using a fire stone" — powered by Coveo's semantic index with a custom Semantic-PokEncoder KNN ranking function.
Dual Generative Answer Modes
Switch between Professor Oak (Coveo CRGA) for cloud-backed answers and any Ollama local model for fully offline inference. Model selector always visible in the top bar.
Type & Generation Filters
Click type chips or generation rows in the sidebar to drive Coveo facets. Selecting a result automatically highlights the Pokémon's types and dims all others.
Habitat Map Card
After selecting a Pokémon, the sidebar map card shows all game encounter locations grouped by generation and region, with a live Serebii Pokéarth region image and PokéMaps deep-links where available.
Similar Pokémon Grid
Coveo's "More Like This" returns semantically similar Pokémon. Displayed as 3-column sprite cards below the search results. Click any to instantly pivot the entire dashboard.
Base Stats · Moves · Type Effectiveness
Right panel renders animated stat bars (HP/Atk/Def/SpA/SpD/Spe), a scrollable level-up moves table, and a 2-column type matchup grid (Weak To / Strong Against).

API Routes
MethodRouteDescription
GET/Serves the original Pokédex device UI (index.html).
GET/dashboardServes the dark 3-column dashboard (dashboard.html). Main app entry point.
GET/readmeThis page — styled HTML README.
GET/api/coveo-tokenReturns {token, organizationId}. API key injected server-side — never exposed in HTML/JS.
POST/api/coveo-proxyProxies Coveo REST calls. Body: {method, path, body}. Injects auth header server-side.
POST/api/rgaOllama RGA. Body: {query, context[]}. Returns {answer}.
POST/api/rga-coveoCoveo CRGA (Professor Oak). Returns {answer, citations}.
POST/api/askFull agentic loop. Body: {query}. Returns {message, pokemon_list}.
POST/api/set-modelHot-swaps the active Ollama model at runtime. Body: {model}.
GET/api/modelsLists all locally pulled Ollama models.
GET/images/<filename>Serves artwork from local data/images/ directory.

Quick Start

Clone & create virtualenv

python -m venv .venv && source .venv/bin/activate

Install dependencies

Professor Oak's Note
The AI answer pipeline selects the model based on the dropdown at the top of the dashboard. Choose Professor-Oak (Coveo) for cloud-backed CRGA answers with inline citations, or any local Ollama model for fully offline, grounded RAG using Coveo search results as context. The server-side agent loop in agent.py always retrieves real Pokémon data from the Coveo index before generating — it never hallucinates from weights alone.
Security: Coveo API keys are never exposed to the browser. The /api/coveo-proxy and /api/rga-coveo routes inject the COVEO_ACCESS_TOKEN header server-side for every request. The /api/coveo-token endpoint returns only what Coveo Atomic needs to initialise its headless engine.
